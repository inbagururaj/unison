# Unison

Real autotune works fine. This is different, it doesn't snap your voice to a generic pitch grid, it matches your take to another artist's actual vocal, their notes and phrasing. So you end up sounding like you're singing in their style, not just pitch-corrected.

## How it works

Upload a reference vocal (vocals only, no instrumental) and your own take, recorded in the browser or uploaded. Unison lines them up in time, finds the notes in the reference, and reshapes your take's pitch to match. It uses a vocoder that keeps pitch and voice character separate, so the result still sounds like you, just matched to their notes.

## What we learned

First version cut the take into individual notes, stretched each one to match timing, then pitch-shifted it. Pitch was accurate but it sounded choppy, and big shifts gave it a chipmunk effect.

Switched to a WORLD-based vocoder instead. It separates pitch from voice character and resynthesizes the whole take in one pass, no cutting and stitching notes together. Tested it against the old version on three different reference vocals, it won every time. Dropped the old approach.

## Setup

It's a Python backend (FastAPI) that also serves the built React frontend. It doesn't run from an editor by itself; you need these installed first:

- [uv](https://docs.astral.sh/uv/) (manages Python 3.13 and the backend dependencies)
- [Node.js](https://nodejs.org/) with npm
- [ffmpeg](https://ffmpeg.org/) on your PATH (every upload is decoded through it)
- rubberband CLI (optional, only used by the old notes engine; the app falls back to librosa if it's missing)

Then:

```sh
# build the frontend once
cd frontend
npm install
npm run build

# run the backend, which also serves the built frontend
cd ../backend
uv sync
uv run uvicorn app.main:app --port 8000
```

Open http://127.0.0.1:8000

For development with hot reload, run the backend with `--reload` and `npm run dev` in `frontend/` (it proxies `/api` and `/output` to the backend), then open http://localhost:5173. Tests: `cd backend && uv run pytest`.

## Tech used

- Backend: Python 3.13, FastAPI, uvicorn, python-multipart
- Audio: pyworld (WORLD vocoder, via `pyworld-prebuilt`), librosa (pitch tracking, MFCC features for alignment), numpy, scipy, soundfile, pyrubberband (old notes engine only), ffmpeg
- Alignment: dynamic time warping over MFCC features (`backend/app/align.py`)
- Frontend: React 19, TypeScript, Vite, hand-written CSS, and a hand-coded SVG pitch chart (no UI, icon or chart libraries)
- Tests: pytest
